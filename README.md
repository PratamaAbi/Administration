# Portofolio Administrasi

Website portofolio statis untuk menampilkan profil, keahlian administrasi, contoh proyek, dan kontak.

## Cara menggunakan
1. Unduh dan ekstrak folder proyek.
2. Buka `index.html` di browser untuk melihat tampilan.
3. Edit `index.html` dan ganti `Nama Anda`, inisial, email, lokasi, serta tautan LinkedIn/GitHub.
4. Sesuaikan daftar keahlian dengan kemampuan Anda yang sebenarnya.
5. Ganti proyek contoh dengan proyek latihan atau pengalaman nyata. Jangan mengklaim proyek contoh sebagai pengalaman kerja yang benar-benar pernah dilakukan.
6. Unggah semua file ke repository GitHub.

## Struktur file
- `index.html` — isi dan struktur halaman.
- `style.css` — desain responsif dan tata letak.
- `script.js` — tahun otomatis pada footer.

## Publikasikan melalui GitHub Pages
1. Buat repository baru di GitHub, misalnya `portfolio-administrasi`.
2. Unggah `index.html`, `style.css`, `script.js`, dan `README.md` ke root repository.
3. Buka **Settings → Pages**.
4. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
6. Tunggu proses publikasi, kemudian buka URL yang ditampilkan di halaman Pages.

## Catatan
Template ini menggunakan HTML, CSS, dan JavaScript sederhana. Font Google Fonts memerlukan koneksi internet; jika tidak tersedia, browser menggunakan font cadangan.
